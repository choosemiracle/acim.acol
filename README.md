# 从奇迹到爱｜ACIM × ACOL

一个面向中文读者的《奇迹课程》（A Course in Miracles）与《爱的课程》（A Course of Love）对照学习与实践网站。

## 核心设计

不是逐章机械对齐，而采用“主题谱系”：

1. 分离 → 合一
2. 恐惧 → 爱
3. 宽恕 → 接纳
4. 特殊关系 → 神圣关系 / union and relationship
5. 身体：学习工具 → 真实 Self 的表达
6. ego / personal self → Christ Self
7. 学习 → 直接知晓
8. 给予 → 创造

页面结构：
- 首页：两部课程的全景、主题对照与六个学习入口
- ACIM 深读：课程结构、核心支柱、特殊关系 / 神圣关系、工作应用与常见误用
- ACOL 深读：Book One / Treatises / Dialogues / Forty Days、wholeheartedness、personal self、具身与创造
- 核心概念库：20+ 个双课程核心名词，包含定义、体系位置、常见误读、生活辨认、关联概念与原书线索
- 五层理论地图：实相 → 心智 / 认识 → 关系 → 具身 / 形式 → 实践 / 创造
- 融合地图：本站“五步融合模型”——觉察 → 松开 → 接受 → 关系 → 表达，并明确两书不可强行融合的张力
- 理论深化：ACOL 相比 ACIM 在个体、关系、个人自我、身体与形式、创造、认识与学习上的七层展开
- 生活实修：8 类现实场景、90 秒回归、五步书写、日节律、周复盘
- 生活方法桥：沟通、边界、决策、工作复盘、财务现实表、身体落地、开放问题与如果—那么习惯
- 生活案例库：8 个完整案例，从事件、自动解释到双课程视角、现实方法与下一步行动
- 浏览器本地个人书写（localStorage）

## 原始材料依据

- A Course in Miracles（用户提供 PDF）
- A Course of Love: Combined Volume（用户提供 EPUB）

目前原型只使用少量短引文，其余以中文释义和主题结构呈现。

## 本地预览

```bash
python3 -m http.server 4173
```

然后打开 http://localhost:4173
